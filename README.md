# Forage Decision-Support Framework

This repository contains the dataset and computational implementation associated with the study:

**An Interpretable Multi-Criteria Decision-Support Framework for Forage Species Recommendation and Grass–Legume Intercropping under Environmental Constraints**

The proposed framework integrates Gower-based multivariate similarity analysis, unsupervised ecological structure characterization, scenario-dependent multi-criteria suitability scoring, productivity, and functional complementarity to support perennial forage species selection and grass–legume intercropping recommendations.

## Dataset

The curated dataset contains **112 forage species and cultivars** characterized by climatic, edaphic, morphological, agronomic, nutritional, management-related, and productivity descriptors.

The original integrated database contains **186 fields**, including **3 identification fields and 183 descriptive attributes**.

A selected subset of **27 descriptors** is used to construct the Gower-based multivariate representation:

- 20 climatic-adaptation descriptors;
- 4 soil-related descriptors;
- 2 morphological descriptors;
- 1 productivity descriptor.

Additional attributes are retained for eligibility filtering, agronomic characterization, and recommendation-specific operations.

The dataset used by the framework is available at:

```text
data/forage_dataset.csv
```

## Main Components

The computational framework includes:

- data preprocessing and standardization;
- Gower-based multivariate dissimilarity analysis;
- hierarchical agglomerative clustering;
- ecological suitability scoring;
- productivity integration;
- individual perennial forage recommendation;
- grass–legume intercropping recommendation;
- pairwise compatibility and functional-complementarity assessment;
- ablation analysis;
- ecological–productivity weighting sensitivity analysis;
- candidate-threshold analysis;
- edaphoclimatic scenario-responsiveness analysis.

## Reference Scenario

The baseline environmental scenario reported in the study is:

| Parameter | Value |
|---|---|
| Soil pH | 5.0 |
| Climate | Cerrado |
| Soil texture | Clayey |
| Fertility | Medium |

The individual suitability score combines normalized ecological suitability and productivity using a **60/40 baseline weighting configuration**.

## Installation

Python 3 is required.

Clone the repository and install the dependencies:

```bash
git clone https://github.com/BarretoGrasi/forage-decision-support.git
cd forage-decision-support
pip install -r requirements.txt
```

## Running the Reference Analysis

To reproduce the reference scenario:

```bash
python experiments/run_baseline.py
```

## Scenario-Responsiveness Analysis

Three contrasting edaphoclimatic scenarios are evaluated in the study.

Run:

```bash
python experiments/run_scenarios.py
```

## Sensitivity Analysis

To reproduce the ecological–productivity weighting sensitivity analysis:

```bash
python experiments/sensitivity_individual.py
```

The evaluated configurations are:

- 70% ecological / 30% productivity;
- 60% ecological / 40% productivity (baseline);
- 50% ecological / 50% productivity.

## Reproducibility

The original complete computational script is preserved in:

```text
archive/original_complete_script.py
```

The modular implementation in `src/` reorganizes the computational workflow into reusable components while preserving the methodological structure of the study.

The `experiments/` directory contains scripts intended to reproduce the principal analyses reported in the manuscript.

## Interpretation

The scores generated by this framework should be interpreted as **comparative decision-support indices**, rather than direct predictions of field performance.

The framework is intended to support transparent comparison of forage alternatives under specified environmental conditions. Independent field validation and evaluation using broader datasets remain necessary to assess the external generalizability and agronomic performance of the recommendations.
